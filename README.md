# 多品种多周期生产计划与库存联合优化

东华大学 机械工程学院 智能制造工程专业
《生产系统智能管理与决策》课程设计 —— 对应教材《生产运作管理》第 7 章（生产计划）、第 8 章（库存管理）。

用一个 **MILP（混合整数线性规划）** 模型，把 6 个产品族 × 12 个月的**生产计划（批量与换型）** 和
**库存/缺货决策** 放在同一个目标里联合优化；再用 30 个随机种子的蒙特卡洛仿真，把它和
「固定批量」「EOQ 分别订货」「(s,S) 策略」三个经典基线放在同一套成本口径下比较。

所有数字都由 `src/run_all.py` 实际运行得到，汇总在 `outputs/metrics.json`。

## 1. 运行方式

```bash
cd prod-inventory-opt

# 一键全流程：载入实例 → 求解 MILP → 蒙特卡洛仿真 → 出图 → 写 outputs/metrics.json
python src/run_all.py

# 可选参数
#   --seeds 30   蒙特卡洛种子个数（默认 30，种子编号 0..29）
#   --rebuild    重新生成 data/instance.json（固定 seed=20260415）
#   --quiet      不打印汇总表

# 单独重生成实例
python data/make_instance.py
```

依赖见 `requirements.txt`：numpy / pandas / scipy / matplotlib（无需 pulp、ortools、simpy）。
MIP 使用 `scipy.optimize.milp`（HiGHS 后端），仿真为手写周期盘点逻辑。

实测：`run_all.py` 内部计时 **约 2 秒**（MILP 约 2 s，30 种子 × 4 策略仿真 < 0.5 s）；含解释器启动与出图，命令总墙钟约 5 秒。

## 3. 场景设计

- **6 个产品族**（P1..P6）× **12 个计划周期（月）**。
- 需求：基准月需求 × 季节因子 × 对数正态扰动（σ≈5%），得到 12×6 的**名义需求矩阵**；
  仿真时按每格的 `demand_std = cv × 基准需求 × 季节因子` 重新抽样。
- 季节因子：`[0.85, 0.90, 1.00, 1.00, 0.95, 1.00, 1.05, 1.00, 1.05, 1.15, 1.30, 1.20]`，Q4 明显走高。
- 产能：每期可用总工时 **1841 h**（单班制，**不设加班**），由「名义需求总工时 ÷ 目标利用率 0.89」反算，
  因此总产能 22092 h > 需求 19657 h（可行），但**峰值月 M11 的需求工时达产能的 115.0%**——
  这就是"必须提前生产平滑"的紧约束来源。
- 持有成本取材料成本的 3%/月（约 36%/年，含仓储、资金占用与损耗）；
  缺货惩罚取材料成本的 2.5 倍（含违约金与商誉损失）。

| 族 | 名称 | 单位工时 h/件 | 材料成本 元/件 | 换型成本 元/次 | 持有成本 元/件·月 | 缺货惩罚 元/件 | 初始库存 | 安全库存 | 基准月需求 |
|----|------|----|----|----|----|----|----|----|----|
| P1 | 液压阀体 | 0.9 | 38 | 420 | 1.14 | 95 | 67 | 112 | 320 |
| P2 | 精密齿轮组 | 1.2 | 45 | 520 | 1.35 | 110 | 55 | 91 | 260 |
| P3 | 伺服支架 | 1.6 | 30 | 380 | 0.90 | 78 | 38 | 63 | 180 |
| P4 | 主轴套筒 | 2.0 | 55 | 640 | 1.65 | 140 | 29 | 49 | 140 |
| P5 | 密封组件 | 0.8 | 42 | 460 | 1.26 | 100 | 46 | 77 | 220 |
| P6 | 连杆毛坯 | 1.4 | 26 | 300 | 0.78 | 68 | 34 | 56 | 160 |

实例整体：名义需求 **16087 件 / 19657.1 h**，整体产能利用率 **89.0%**，峰值月 M11 达 **115.0%**。

## 4. 数学模型（详见报告）

**变量**（4·T·N = 288 个，其中 72 个 0/1）：`x[t,i]` 生产量（**连续**）、`y[t,i]` 是否开机（0/1）、
`I[t,i]` 期末库存、`B[t,i]` 期末缺货（欠交/backlog）。

**约束**

1. 库存平衡（缺货回补式）：`I[t,i] - I[t-1,i] - x[t,i] - B[t,i] + B[t-1,i] = -d[t,i]`，
   其中 `I[-1,i] = 初始库存`、`B[-1,i] = 0`，故 t=1 的右端为 `init_i - d[0,i]`。
   `B` 是"欠交订单"：下一期先还欠、再满足当期需求，平衡式中的 `+B[t-1] / -B[t]` 正是这个含义。
2. 产能：`Σ_i h_i·x[t,i] ≤ cap_t`（无加班）。
3. 开机联动：`x[t,i] ≤ M[t,i]·y[t,i]`，取紧的 `M[t,i] = cap_t / h_i`。
4. 仓库容量：`I[t,i] ≤ 2 × 基准月需求`。
5. 未加安全库存硬约束（经济性由缺货惩罚定价），代码中保留 `enforce_safety_stock` 开关。

**目标**：`min Σ K_i·y + Σ h_i·I + Σ p_i·B + Σ c_i·x`
= 换型 + 持有 + 缺货惩罚 + 材料。

**求解**：把上述化成 `c @ z` 线性形式，`scipy.optimize.milp` 配 `LinearConstraint`（228 行，
72 行等式 + 156 行不等式）与 `Bounds`，HiGHS 求得 **全局最优（gap = 0）**。

## 5. 基线策略与产能截断规则

| 基线 | 决策规则 |
|------|----------|
| 固定批量 | 每族 `Q_i = 1.2 × 平均月需求`；库存位置 `IP = 库存 − 欠交`，`IP < 安全库存` 时下 `Q_i` |
| EOQ 分别订货 | `Q_i = sqrt(2·K_i·D_i / h_i)`（D 用**月**均需求、h 为月持有成本，量纲一致）；订货间隔 `n_i = max(1, round(Q_i/D_i))` 月，按产品序号错开相位，每到自己的订货期下一次 `Q_i`（本例 Q/D = 1.5～2.4，只有 P1 退化成每月一次） |
| (s,S) 策略 | `s_i = 安全库存`，`S_i = s_i + Q_i`；`IP < s_i` 时补到 `S_i` |

三个基线都**只看本族库存状态**，完全不看共享产能，因此在旺季会互相挤占产能。

**截断规则**：若某期 `Σ h_i·req_i > cap_t`，按单位工时缺货惩罚 `p_i/h_i` 降序分配产能
（高价值密度族先装满），分不到的产量当期作废、不跨期结转（对应"产能不足时丢单"）。
做了一次鲁棒性检查：把规则换成**等比例削减**，四个策略的成本排序与 MIP 的优势基本不变（见 §7）。

## 6. 仿真协议

- 30 个种子（0..29），每个种子用 `numpy.random.default_rng(seed)` 重抽样需求：
  `d = max(0, round(名义需求 + σ·z))`。
- 每期顺序：**先决策产量 → 再实现需求 → 再结算库存/缺货**。
  `served = min(期初库存 + 产量, 当期需求 + 上期欠交)`，`I_t = 可服务量 − served`，`B_t = 需求 − served`。
- 四个策略用**同一套成本口径**（同一份 `simulate_path` 代码）：
  换型 `K_i·1[x>0]`、持有 `h_i·I_t`、缺货 `p_i·B_t`、材料 `c_i·x`。
- **MIP 计划在仿真中固定**：`x[t,i]` 直接取模型最优解，不随实现需求重优化；
  基线则是按实现库存状态反应的策略（这一点对基线更有利，属于故意保留的不对称）。
- 指标：总成本、平均期末库存（6 族合计）、缺货量（期末欠交累计，件·月）、
  未满足需求件数、满足率 `fill rate = Σserved / Σdemand`、
  周转率 `= 期内去化件数 / 平均库存件数`。输出**均值 ± 标准差**（30 个种子）。

## 7. 结果（`outputs/metrics.json`，30 个种子）

### 7.1 MILP 解（名义需求，确定性）

| 项 | 数值 |
|----|------|
| 目标值 | **649,640.21 元** |
| 材料 / 换型 / 持有 / 缺货 | 623,141.00 / 18,020.00 / 8,479.21 / 0.00 |
| 投产总量 / 换型次数 | 15,818 件 / 40 次 |
| 变量 / 约束 | 288（72 个 0/1）/ 228 |
| 求解时间 / MIP gap | 约 2 s / 0 |

仿真器在名义需求上复核得到 649,640.21 元，与模型目标值相对差 2e-14（成本口径一致）。

### 7.2 蒙特卡洛（30 种子，均值 ± 标准差）

| 策略 | 总成本（元） | 满足率 | 平均库存（件） | 未满足需求（件） | 周转率 | 相对 MIP 成本差 |
|------|--------------|--------|----------------|------------------|--------|-----------------|
| **MIP 联合优化** | **732,886 ± 38,406** | **98.93%** | 692.3 | **173.1** | 23.42 | — |
| 固定批量 | 982,638 ± 55,319 | 95.71% | 183.0 | 688.9 | 85.04 | +34.08% |
| EOQ 分别订货 | 1,580,360 ± 59,833 | 88.02% | 1,829.0 | 1,923.6 | 7.75 | +115.64% |
| (s,S) 策略 | 866,363 ± 39,512 | 97.00% | 725.7 | 481.5 | 21.48 | +18.21% |

- 相对最强的基线 (s,S)，MIP 总成本低 **18.21%**（每月折合约 1.1 万元），
  满足率高 **1.92 个百分点**，未满足需求只有它的 **1/2.78**；
  相对固定批量低 **34.08%**，相对 EOQ 低 **115.64%**。
- MIP 的库存（692 件）与 (s,S)（726 件）相当，但把库存放在**旺季之前**，
  所以同样的库存水平换来更高的满足率——优势来自"时点"，不是"多囤"。

### 7.3 成本构成（占各自总成本）

| 策略 | 材料 | 换型 | 持有 | 缺货惩罚 |
|------|------|------|------|----------|
| MIP | 85.03% | 2.46% | 1.34% | 11.18% |
| 固定批量 | 61.14% | 2.69% | 0.27% | 35.89% |
| EOQ | 41.55% | 1.19% | 1.60% | 55.65% |
| (s,S) | 72.30% | 1.70% | 1.21% | 24.80% |

EOQ 的 55.65% 和固定批量的 35.89% 都花在缺货惩罚上。EOQ 的批量相当于 1.5～2.4 个月需求，
且 P1 的订货间隔退化为 1 个月（Q/D = 1.49 取整），于是 P2/P4/P6 同月下单的那一期请求 2164 h
（产能的 117.5%），P1/P3/P5 下单的那一期只有 1417 h——产能时紧时松、被截断的同时仓库还堆到 1829 件，
这正是"各族独立按 EOQ 订货、不看共享产能"的典型后果。

### 7.4 鲁棒性（把截断规则换成"等比例削减"）

| 策略 | 相对 MIP 成本差 |
|------|-----------------|
| 固定批量 | +37.63% |
| EOQ | +95.98% |
| (s,S) | +18.15% |

排序不变、MIP 的优势幅度基本不变，说明结论不依赖某一种产能分配规则。

## 8. 口径说明（重要）

1. **数据是合成场景**，由 `data/make_instance.py` 固定 `seed=20260415` 生成，**不是真实工厂数据**；
   参数（工时、成本、需求）是为了让"产能紧、季节性强、换型有成本"这三个特征同时成立而设定的，
   数量级参考一般机械装配类产品，不具备行业统计意义。
2. **MIP 计划一旦求出就固定**，在 30 个种子的仿真里不再重优化；基线则是按实现库存状态反应。
   也就是说 MIP 在"信息"上吃亏（开环计划）、在"产能协同"上占优，这是刻意的对比设计。
3. **基线受同一产能约束**：三个基线都只按本族库存下单，产能不够时按 §5 的规则截断，
   截断的产量当期作废。若允许跨期补产，基线成本会下降、MIP 的优势会缩小（本设计未做这种放宽）。
4. **成本口径四方一致**：都走同一个 `simulate_path`，换型按"某期某族有产量"计一次，
   持有按期末库存计，缺货按期末欠交计，材料按投产量计；`outputs/metrics.json` 里
   `deterministic_nominal.mip.total_cost` 与 MILP 目标值相对差 2e-14，可作为口径自检。
5. **缺货量有两种口径**：`shortage_units` 是期末欠交的逐期累计（件·月，同一件欠两个月算两次），
   `unserved_units` 是 12 个月内未被满足的需求件数（唯一计一次）；正文表格用后者。
6. **持有成本率与缺货惩罚是外生假设**（3%/月、2.5 倍材料成本）。缺货惩罚越大，
   MIP 相对基线的成本优势越明显（因为优势主要来自减少缺货），本设计未做该参数的敏感性分析。
7. `x[t,i]` 取**连续**量（批量按件取整会引入 0.5% 以内的目标变化），0/1 变量只用于换型。

## 9. 已知局限

- 需求是独立同分布的月度随机量，未建模需求相关性、预测更新与滚动计划（MIP 是单次开环计划）。
- 生产提前期为零（当期投产当期可用），未含在制品、良率与设备故障。
- 未考虑多级 BOM、多工厂/多产线，产能只用一个总工时约束刻画。
- 期末库存无残值处理（末月不再为下一年备货），热力图中 M12 产量明显偏低即由此而来。
- 基线只实现三个经典规则，未与"人工经验排产"或"滚动优化"对比。
